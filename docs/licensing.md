# Licence and commercial use

ScoutBankAI is currently released under **Apache License 2.0**. [LICENSE](../LICENSE) is the operative licence; this page explains the product choices and does not add restrictions.

For an open-source launch, keeping Apache 2.0 is a practical choice. Commercial reuse is allowed under its terms. Maintainers can charge for hosting, integration and support; using the code does not require buying those services.

If the goal is visible source with payment required for commercial use, that is a different licensing model:

| Goal | Relevant option | Consequence |
| --- | --- | --- |
| Broad open-source adoption, with paid services | Apache 2.0 | Commercial users can use the licensed code without buying a separate licence |
| Open source with stronger sharing obligations | AGPLv3, potentially with a separate commercial offering | Commercial use remains allowed; network-use source obligations can apply to modified versions |
| Permit defined noncommercial uses and separately license commercial uses | A source-available licence such as PolyForm Noncommercial plus a commercial agreement | Commercial permissions are restricted; this should not be described as OSI open source |

AGPL is not a general prohibition on free commercial use. PolyForm Noncommercial has specific permitted-purpose and organisation provisions; it should not be described as a universal requirement that every institution pays.

Changing a licence file does not withdraw existing Apache grants. Future relicensing needs a review of existing releases, contributor rights and commercial terms.

Primary references: [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0), [GNU AGPLv3](https://www.gnu.org/licenses/agpl-3.0.en.html), [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0), and the [Open Source Definition](https://opensource.org/osd).
